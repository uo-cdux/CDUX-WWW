Overview

This website can only be modified by CDUX students. Its source is accessed through Subversion. (See here for more information on Subversion usage.)

The command to check out the website is:
svn co svn+ssh:// < your ix username > @ix.cs.uoregon.edu/home/users/hank/SVN/WWW

To keep the website look and feel consistent, a script automatically adds headers and footers, and automates all references to people, publications, and research projects. You can invoke the script by calling "make". The Makefile does several actions, including calling a script called "generator". It places the resulting HTML files in a directory called "www". The root of the website is called index.html, and so (on macs) you can access the website created by make with "open www/index.html".

Note that students only have access to checkout the source for the website, make modifications, look at their local copy of the website (made via "make"), and commit their modifications. Students cannot install their local copy onto the team's webpage (http://cdux.cs.uoregon.edu), since that requires Unix permissions that only Hank has. Therefore, the pattern for development is one where Hank and students make changes to the webpage regularly, and that Hank pushes the resulting webpages live when appropriate. (If you want a news item or research result to get published on the website, then, you should make changes on SVN and email Hank and ask him to push the changes live.)

How to:
  • Add your home page
  • Add a publication
  • Add a news item

Adding a Home Page

  • Your home page should go in the directory WWW/people/yourLastNameInLowerCase/
  • There should be two files in that directory:
    • page: contains the contents of your home page
    • thumb: contains information to make a thumbnail (used for other pages)
  • You also should place images in images/people.
    • One image must be exactly 150 pixels in width and 200 pixels in height. This image is used for your thumbnail. In case you don't feel comfortable with image manipulation, the script WWW/images/people/cropper contains some examples of how I used the PNM tool to extract thumbnails from full-size images.
    • Many folks also have a larger sized image for their homepages.
    • The image must be exactly 150x200. Other sizes will cause formatting errors.
    • Note: do not only add one (large) image and use that image as a thumbnail. This leads to slow page load times.
  • After your home page is added, the final step is to insert links to yourself on other pages. You should definitely add a link on our people page (found in WWW/top/people) and also in individual research projects that you are working on (found in WWW/research/TheResearchProjectName/page). You do this by inserting a macro that will be replaced by the "generator" script. Your macro is PERSON:yourLastNameInLowerCase.

Contents of thumb file

The thumb file should contain exactly three lines:
  • Line 1: Your name as you would like it to appear
  • Line 2: the name of the 150x200 image in the images/people directory.
  • Line 3: your title. If your title needs multiple lines, then use the < br > command.

Example:
Charlotte Childs
childs_cropped.png
Undergrad Researcher

Also, if you are a student, please use one of the following titles:

  • Undergrad Researcher
  • M.S. Student
  • Ph.D. Student
  • Ph.D. Candidate

Contents of page file

The easiest way to create this file is to copy an existing file and modify it. Further, I recommend you follow a style similar to the ones already in use.


Adding a Publication

Publications are stored in the WWW/pubs directory. They are divided by publication year, and then each publication gets its own subdirectory. The subdirectory should have the first author's last name followed by the venue. So a 2015 publication by Hank at LDAV would be in WWW/pubs/2015/ChildsLDAV. If you have multiple publications, then you can add a "A" or "B" to the end. (I.e., this about a consistent convention and not about macros.)

Files for Setting Up a Publication

Publication directories (e.g., WWW/pubs/2015/ChildsLDAV) must contain specific files:
  • authors: an ASCII text file containing the authors of the paper. This file can be multiple lines long. This can have links encoded. Note that the form for encoding links to CDUX authors (which can be relative links) is different than external collaborators. See WWW/pubs/2015/LarsenPacVis for an example of authors that have both relative links and absolute links.
  • bib: an ASCII text file containing the bibtex citation information.
  • venue: an ASCII text file containing the name of the venue the work was published at. This may contain links. See WWW/pubs/2015/LarsenPacVis for details.
  • title: an ASCII text file containing the title of the work.
  • thumb.jpeg: a JPEG file containing a 125x125 pixel image to serve as a thumbnail.
    • Note: many directories also contain a second image file with the original image that the thumbnail was derived from. This is not required for the website, but keeping the original image around is a good practice.
  • A reference to the paper. This can take one of two forms:
    • A PDF of the paper. If the directory is ChildsLDAV, then the file must be called ChildsLDAV.pdf.
    • An ASCII text file with a link to a place to obtain the paper. If the directory is ChildsLDAV, then the file must be called ChildsLDAV.link. The contents of the file are a single line containing a website, e.g., http://www.ldav.org.
  • note: This is an optional file for annotating your publication with a note. Examples include "Best Paper" or "Accepted for Publication".

Making Your Publication Show Up on the Website

When adding a publication, you should consider adding it to three types of pages:
  • Your home page.
  • The research page associated with the publication. This page will be located at WWW/research/projectName/page.
  • The CDUX publications page at top/publications.
  • (Do not automatically add the paper to Hank's personal home page. He will do this on his own from time to time.)

You should add your publication using its macro. The macro for a publication located in directory WWW/pubs/2015/ChildsLDAV is PUBLICACTION:2015/ChildsLDAV. Each publication turns into an HTML table entry. If you are adding publications where none have previously been location, then you will need to use the START_CTABLE and END_TABLE macros before and after the publication macro.

Advanced Copies of Your Publication

If your paper has been accepted and you want it to appear on the website, then that is fine. It is your choice on whether to include the PDF, but I personally recommend you just add a link to the venue that will publish it (and not the PDF until it is published). Also, feel free to add the publication to your home page, and to the corresponding research page. However, do not add it to the team's publication page until it is published and there is a PDF.


Adding a News Item

Steps for adding a news item:
  • Make a directory under WWW/news/YEAR/newsItem. Replace YEAR with the correct year and newsItem with a short descriptor for your news item.
  • Add files to your new directory:
    • date: the date when the event happened. Please follow a form of Month Day, Year with no abbreviations. E.g., October 31, 2015.
    • title: the title for your news item. This should be no more than 80 characters.
    • body: the body of your news item. This may include links, HTML code (typically bullets), etc.
    • tags: a file containing describing the categories for your news item. By default, your news item will go in the "all" page. But there are also sub-pages that focus on news items in particular categories. The tags file describes which of these sub-pages your news item should go in. The available tags are:
      • student: used for the "Student Successes" sub-page.
      • awards: used for the "Awards and Recognition" sub-page.
      • funding: used for the "Funding" sub-page.
      • outreach: used for the "Outreach and Leadership" sub-page.
      • personnel: used for the "Personnel" sub-page.
      If your news item is appropriate for multiple categories, then you should list multiple tags in your file. They can be one per line, or all on one line.
    • image (optional): an image to include. The file should be an ASCII text file and contain exactly two lines. The first line should be the location of the image, presumably in WWW/images/events. The path should be relative to WWW, e.g., a file in WWW/images/events/party.png would be represented as "images/events/party.png" in the first line of the file. The second line is the width of the image in pixels.
  • Add your news item to the file top/news (which contains the web page for all news items). Your news item should be inserted as a macro. The "generator" script will replace your macro with HTML code corresponding to the title/body/date/image files. The macro for your news item is: "NEWS:YEAR/newsItem".
