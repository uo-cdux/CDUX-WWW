Basic Information

Subversion (SVN) is a revision control system. SVN usage is well documented on the internet, including this page which shows the basics.

CDUX hosts four separate SVN repositories:

  • Papers: dedicated to publications at conferences/journals/workshops.
  • Code: dedicated to code shared between team members.
  • Milestones: dedicated to documents for milestones.
  • WWW: dedicated to our team website.
Please make sure you use the correct repository, i.e., add publications only to the Papers repo, your code only to the Code repo, etc.


All SVN repositories are stored on ix, in the directory /home/users/hank/SVN. In order to access the repositories, you need:

  • An account on ix.cs.uoregon.edu
  • Membership in the Unix group hanksvn. You can check whether you are in this group by logging into ix and running the Unix command "groups". If you are not in hanksvn, email Hank and ask him to add you.

Our SVN repos are accessed via the svn+ssh protocol. Example usage includes:

  • svn ls svn+ssh://< YOUR IX USER NAME > @ix.cs.uoregon.edu/home/users/hank/SVN/< REPO >
  • svn co svn+ssh://< YOUR IX USER NAME > @ix.cs.uoregon.edu/home/users/hank/SVN/< REPO >
    • Note: svn co with the svn+ssh protocol requires you to issue your password twice.
    • Note 2: this command would check out the whole repository. Often you will only want sub-directories.

Papers

The Papers repo is organized by year. If your last name is Smith and you wanted to create a publication that would be published in 2016 at venue VenueName, then the publication should be stored in directory 2016/SmithVenueName. If you have multiple publications at that event, then you can append 'A', 'B', etc. It is fine (and expected) for VenueName to be abbreviated to some short form. Note that this naming convention has not been well followed up until this point.

Creating a directory for your publication in the SVN repo:
svn mkdir svn+ssh:// < USERNAME > @ix.cs.uoregon.edu/home/users/hank/SVN/Papers/2016/SmithVenueName

Accessing your directory:
svn co svn+ssh:// < USERNAME > @ix.cs.uoregon.edu/home/users/hank/SVN/Papers/2016/SmithVenueName
(Note: must enter password twice!)

Also: I have noticed that many folks are downloading template LaTeX files from conference websites, and leave the "template" name for their paper. I encourage you to rename "template" to a more meaningful name for two reasons:

  • The name "template.pdf" is not unique, and can collide with other publications, including your own (when you start publishing multiple papers). This can come back to bite you in multiple ways.
  • Reviewers can sometimes see the names you give your submission. If they seem the name "template.pdf", it gives a sloppy impression.

Code

Code is placed at a top-level directory. Try to pick a short-ish name for your directory.

Creating a directory for your code in the SVN repo:
svn mkdir svn+ssh:// < USERNAME > @ix.cs.uoregon.edu/home/users/hank/SVN/code/< NAME >

Accessing your directory:
svn co svn+ssh:// < USERNAME > @ix.cs.uoregon.edu/home/users/hank/SVN/code/< NAME >
(Note: must enter password twice!)


Milestone Documents

Milestone documents are stored in their own directory. For a milestone document of type TYPE, in year YEAR, and for student STUDENT, then the directory should be TYPE/YEAR/STUDENT.

Creating a directory for your code in the SVN repo:
svn mkdir svn+ssh:// < USERNAME > @ix.cs.uoregon.edu/home/users/hank/SVN/Milestones/TYPE/YEAR/STUDENT

Accessing your directory:
svn co svn+ssh:// < USERNAME > @ix.cs.uoregon.edu/home/users/hank/SVN/Milestones/TYPE/YEAR/STUDENT
(Note: must enter password twice!)

The types of milestone documents are:

  • DRP_Proposal: DRP proposals
  • DRP_Report: DRP reports
  • Orals_StudyPlan: Study plans for the Oral Exam
  • Orals_Report: Oral exam reports
  • Thesis: Theses
